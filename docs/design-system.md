# LongPi 设计规范（v1，2026-09-30）

唯一依据。所有 LongPi 界面（健康页、设置分区、引导、对话卡片、右栏）只用这里的变量和组件。
目标：看起来是 DSH 的一部分；安静、克制、排版严谨；浅色/深色自动跟随 DSH。

## 0. 硬规则

- 颜色只用 `--lp-*` 变量（全部映射到 DSH `--dsw-*`），组件样式里禁止写十六进制色值。
- 字号只用 12 / 13 / 14 / 15 / 17 / 24 / 36（大数字）；字重只用 400 / 500 / 600。禁止 10、11px。
- 间距只用 4 / 8 / 12 / 16 / 20 / 24 / 32 / 48；组件内部（标签与控件、图标与文字、提示条内边距）另允许 6 / 10 / 14。
- 每个组件里用到的 `lp-*` 类名都必须在样式里有定义（`test/css-classes.mjs` 构建期检查）。
- 同一个类只定义一次；禁止用后写的规则覆盖前面的定义。
- 不再使用：虚线边框（上传拖放区除外）、胶囊形按钮、`lp-rise` 切换动画、界面控件上的蓝色。

## 1. 颜色角色

| 变量 | 用途 |
|---|---|
| `--lp-bg` / `--lp-layer` | 页面底 / 卡片底 |
| `--lp-well` | 次级底色（分段控件、提示条、元数据标签） |
| `--lp-ink` / `--lp-ink-2` / `--lp-ink-3` | 主文字 / 次文字 / 说明文字；`--lp-ink-4` 只用于占位符 |
| `--lp-line` / `--lp-line-strong` | 分隔线、卡片描边 / 控件描边 |
| `--lp-accent` / `--lp-on-accent` | 唯一强调色 = DSH 品牌色（黑，深色模式反白）：主按钮、选中下划线、开关开、筛选选中、进度填充 |
| `--lp-data` | 图表线与数据点（唯一的蓝色，只在图表里用） |
| `--lp-good/warn/bad` + `-wash` + `-ink` | 语义状态：浅底 + 深色文字/图标 |

## 2. 字号阶梯

| 类 | 规格 |
|---|---|
| `.lp-h1` 页面标题 | 24/32/600 |
| `.lp-h2` 区块标题 | 17/24/600 |
| `.lp-h3` 卡片标题 | 15/22/600 |
| 正文 | 14/22/400，段落最大宽度 40em |
| `.lp-muted` 次要正文 | 14/22 ink-2 |
| `.lp-small` 列表行/控件 | 13/20 |
| `.lp-caption` 说明、表头、眉题 | 12/18 ink-3 |
| `.lp-num-lg` 大数字 | 36/44/600 等宽数字；单位 14 ink-2 |
| `.lp-num-md` 中数字 | 24/32/600 |

## 3. 布局

- 内容最大宽度 960px，左右 40px（容器 ≤760px 时 20px）。
- 页头：左（眉题 → h1 → 一行元信息）、右（32px 控件行：人员选择｜添加家人｜去健康对话｜刷新）；≤760px 改两行。
- 引导横幅：页头下 16px，40px 高，well 底，圆角 12px。
- 一级标签 40px 高，选中 = ink + 600 + 2px accent 下划线；hover 只变文字色；整行 1px line 底线。
- 二级入口（方案/档案/赛季/研究）：一级标签行最右侧的「更多」菜单；进入二级页时标签行出现临时选中标签「方案 ×」。
- 两列卡片网格 gap 12px，≤720px 单列，落单项占满整行。
- 区块之间 32px，卡片之间 12px，区块标题到内容 12px，页脚上方 48px。

## 4. 组件（base.ts，全站唯一实现）

- **卡片 `.lp-card`**：layer 底，1px line 描边，圆角 12px，内边距 20px（窄屏 16px），无阴影。`.lp-card-head`：flex 两端对齐，底部 12px；左 h3（+ⓘ），右 caption 或文字按钮；标签放在卡片头下一行。
- **区块 `.lp-section`**：grid gap 12px；`.lp-section-head` = h2 + 右侧动作。
- **按钮**：DSH `Btn`（primary 黑 / outline，渲染时自动带 `.lp-btn`）作为唯一按钮；在 LongPi 内统一为 md 32px、sm 28px、圆角 8px、13/12px（DSH 原生是胶囊形，这里统一覆盖）。`.lp-linkbtn` 统一成 outline 32px 圆角 8px。`.lp-textbtn`：纯文字 13px ink-2，hover 下划线。`.lp-iconbtn`：32×32 ghost。
- **标签**：`.lp-tag`（元数据：20px 高、圆角 4px、12px、ink-2、well 底）；`.lp-status`-类状态标签 `.lp-badge` + `-good/-warn/-bad/-neutral`（22px、圆角 6px、12/500、浅底深字）。
- **表格 `.lp-table`**：表头 12px ink-3 左对齐，单元格 13/20 内边距 10px 12px，顶部对齐，行线 1px line；首列 nowrap；数字列右对齐。
- **列表行 `.lp-row`**：最小 44px，行线 1px line；可点击时右侧 chevron + hover 底色。
- **分段控件 `.lp-seg`**（筛选、性别等）：well 底，内边距 2px，圆角 8px，项 28px，选中项 layer 底 + 轻阴影；计数 12px ink-3；计数为 0 置灰。
- **表单**：`.lp-field`（grid gap 6px）> `.lp-field-label`（13/500）+ `.lp-input`/`.lp-select`（36px、圆角 8px、1px line-strong、自定义下拉箭头）；错误 `.lp-form-error` 12px bad；复选框 16px accent-color；开关统一 `Switch`（开 = accent）。
- **提示条 `.lp-callout`** + `-info/-warn/-good`：well/wash 底，圆角 10px，内边距 12px 14px，13/20；`.lp-callout-title` 13/600。
- **空状态 `.lp-empty`**：左对齐，纵向 24px；图标 20px ink-3 → 14/500 标题 → 13 ink-2 说明 → 可选 outline 按钮。数据为 0 时不显示筛选栏。
- **线性进度 `.lp-bar`**：6px，圆角 3px，轨道 line，填充 accent。
- **步骤进度 `.lp-progress-steps`**（深度分析）：纵向，每步 32px，16px 状态点（完成 accent 实心 ✓ / 进行中 2px 描边转圈 / 未开始 1px 空心），点间 1px 竖线。
- **步骤条 `.lp-stepper`**（引导）：横向，20px 圆点 + 13px 标签，连接线 24px。
- **上传区 `.lp-upload-simple`**：1px 虚线 line-strong、圆角 12px、内边距 24px、居中。

- **数字格式**：小于 10 保留两位、10 以上保留一位；% 前不加空格；日期一律「9 月 30 日」（跨年加年份），不用 ISO 或「26/09」。
- **标题**：卡片标题允许换两行；截断必须带「…」。

## 5. 页面级

- 标签页内不再放「眉题 + h2」页头；卡片标题不与标签页名重复。
- 页脚一行，12px ink-3，上边线 1px line。
- 眉题不显示版本号（版本号放到设置页）。
- 深度分析：开关一行 + warn 提示条；状态和进度合并为一张卡；报告做成摘要卡 + 「打开完整报告」；器官表用 `.lp-table`；问题看板每题一张卡，长文折叠。
- 设置页：区块 15/600 标题，区块之间 1px 分隔线；所有开关用 Switch；折叠区用自定义 chevron。

## 6. 文件归属（styles/）

`tokens.ts`（变量 + 字号）→ `base.ts`（第 4 节组件）→ 各页面模块：`shell.ts`（页头/标签/横幅/人员/页脚）、`overview.ts`、`indicators.ts`（化验/睡眠/运动/日程/问 LongPi）、`plan.ts`（方案/档案/自测/草案/赛季/研究）、`analysis.ts`、`settings.ts`（设置/提醒/隐私/连接）、`onboarding.ts`、`chat.ts`（对话卡片/右栏/提醒胶囊/首页输入桥）。页面模块只写本页特有的布局，不重复定义 base 里的组件。
