# 长寿图鉴：玩法与设计定稿

状态：定稿 1.1（2026-10-04，已纳入第三轮用户模拟的修订）。本文只定玩法机制和设计风格，实现在后续 session 里迭代 dsh-plugin-longpi 时完成。

依据：
- 三轮独立用户模拟：`docs/usertest/round1/`、`round2/`、`round3/`。每轮 6 个子代理，各扮演一个 DSH 用户，只读用户能看到的材料，互相看不到。
- 0.6–0.7 版图鉴的代码和卡池数据。
- 方法库元数据：`catalog.json`、各技能的 `skill.json` 和 `references/claims.md`、`data/biological_variation.json`。

视觉参考：`preview/codex/index.html`，像素风，直接用浏览器打开。其中「卡面设计」「全部卡片」两页是视觉定稿；「试玩一个赛季」「玩法与概率」两页演示的是已废弃的第二版玩法（日常袋、按章收集），只看视觉，不看规则。

## 0. 决策摘要

| # | 决定 | 依据（详见第 1 节） |
| --- | --- | --- |
| 1 | 图鉴的主线是**两周的个人小实验**：三选一 → 做 → 揭晓。揭晓就是「开包」时刻。 | 三轮里唯一真正改变行为、被多数人留下来的部分 |
| 2 | 研究卡组成**图书馆，随时免费读**，不靠抽卡解锁 | 把论文锁在随机抽卡后面，抽到的和自己无关 |
| 3 | **卡包只有两种**：实验包（赛季开始、每做完一个实验）、复查包（本人复查或补检查后）。没有日常袋、每周上限、连续打卡 | 日常袋被说成「白送」「清红点」「教我一周只测三天」 |
| 4 | DSH 工作日里只有一个提示位，内容只有两种：**起身提醒**（手环确认才算数，不挂任何奖励），以及**揭晓当天的一次「有一张实验卡可以翻了」** | 「做了」不验证等于奖励撒谎；拆包挤掉起身提醒；揭晓没人知道，图鉴「像不存在」 |
| 5 | 提示不写时间承诺、不显示健康数字；会议和演示模式下隐藏；时段按「我的白天」，首次使用时询问。**健康栏默认不显示任何个人数字**，点一下才显示，60 秒后自动收起 | 「回来正好跑完」做不到；临时投屏是三个人唯一的卸载理由，而浏览器检测不到系统级屏幕共享 |
| 6 | 证据颜色：铜＝细胞，银＝动物，紫＝人群研究或随机试验的事后分析，金＝随机试验的主要结局。颜色跟着「一句话」里的主结论走。**颜色只是标签**，不做稀有度，金卡没有扫光和闪点 | 事后分析和主要结局不该同级；唯一的金卡讲慢阻肺的痰，金色被读成「最靠谱」 |
| 11 | 揭晓只说**「超出平时波动」或「在平时波动内」**，不说「真实变化」，也不说是实验带来的；每个实验开始前定一个主要结果，公开判定阈值；能按天随机的实验提供随机版 | 前后比较没有对照，同时看多个指标会有碰巧超出 |
| 7 | 家人的就诊和复查**只记足迹卡**，不给卡包 | 「拿母亲看病换一个卡包，总觉得别扭」 |
| 8 | 视觉是**像素卡牌风，只限图鉴内部**。起身提醒和健康页入口用 DSH 原生样式 | 美术被多人喜欢；工作区要安静 |
| 9 | 文案：客观转述，不加否定尾巴；关键限定写进一句话；正文白话；没有个人内容的栏位整栏隐藏 | 用户反馈；「只……不……」「看了等于没看」 |
| 10 | 红线不变：不付费、不交易、未满 18 岁关闭、可随时关闭、结果与奖励不跟指标好坏挂钩 | 合规与信任 |

## 1. 为什么这样定

三轮测试用同一组 6 个人设：27 岁后端（玩《小丑牌》）、38 岁产品负责人（两个孩子、常投屏）、46 岁技术总监（高血压、讲证据）、31 岁自由设计师（夜猫子、只有手表数据）、58 岁生信教授（挑科学错误、照顾 80 多岁的母亲）、24 岁应届全栈（网络梗、厌恶说教）。每轮都是新的子代理，没有看过前几轮的材料。

| 平均分（1–10） | 第一轮：抽论文卡 | 第二轮：你的卡＋日常袋 | 第三轮：定稿 1.0 |
| --- | --- | --- | --- |
| 好玩 | 4.5 | 5.5 | 4.8 |
| 有用 | 3.3 | 4.7 | 5.3 |
| 会坚持两个月 | 2.3 | 3.8 | 4.3 |
| 愿意推荐 | 2.8 | 4.3 | 4.2 |

「好玩」在第三轮下降，是因为取消了日常拆包，这是有意的取舍：前两轮的拆包乐趣两三周就耗尽，还造成「清红点」和刷包。第三轮的修订（本文 1.1）针对的是「坚持」：揭晓通知、实验目录、投屏隐私。

关键发现：
- **第一轮**：奖励给的是「记了一条」，不是「做到」；抽到的卡和自己无关；「算过」红章绝大多数卡永远点不亮。实测：一份 52 项指标的完整示例档案，只能让 179 个方法中的 12 个算出个人结果，其中 5 个只用到年龄。文案有内部用语和法务腔。
- **第二轮**：实验卡最有价值（「像给自己跑 A/B 测试」）。六人里五人在模拟中养成了饭后走路，原因是手环自动记录、什么都不用点。新问题：「做了」不验证；「正好跑完」做不到；拆包挤掉起身提醒；投屏露出健康信息；卡包太便宜，攒着不拆反成待办；实验要求 14 天全勤、对比指标不对（拿步数评价「饭后走路」是循环论证）；睡眠分组口径错（论文用自报，手环测得更短）。
- **第三轮**：起身提醒第一次被所有人留下（「算我用过最不烦的健康插件」），六人里五人真的起身。「超出你的正常波动」被认为「值钱」。新问题：两次揭晓之间图鉴「像不存在」，揭晓了也没人知道；临时投屏（日历上没有）是三个人唯一的卸载理由；「真实变化」承诺过头；实验目录不贴生活（周末补觉、吃食堂外卖、起夜、想看 LDL）；吃降压药就「先问医生」太宽；唯一的金卡讲慢阻肺的痰；China-PAR 超出年龄或已有冠心病时不该出数。详见 `round3/summary.md`。

## 2. 在 DSH 工作日里：一个提示位

这是 LongPi 在用户工作时**唯一**主动出现的地方。只放两种内容：起身提醒，以及揭晓通知（2.1）。

| 项 | 规则 |
| --- | --- |
| 触发 | 手环显示连续久坐 ≥ 90 分钟，**并且**当前有一个 agent 回合已经跑了 ≥ 60 秒（只有这时用户是在干等；「有 agent 在跑」对重度用户全天成立，不能当条件）。没有手环时，用 DSH 内连续活跃时长估计（各工作区合并计算） |
| 位置 | 右侧「健康」栏的顶部一行；健康栏没打开时，是界面右下角的一个小条（`shell.overlay`）。不进入对话区，不进入 agent 输出 |
| 文字 | 「已经坐了 1 小时 40 分。起来走两分钟？」［好］［今天别提醒了］。不写「回来正好跑完」这类时间承诺；不出现任何健康数字和指标名 |
| 确认 | 点［好］后 10 分钟内，手环检测到起身走动才算一次「起身」。没有手环就只是提醒，不记录。不点也行，自己起身了手环一样会记 |
| 奖励 | **没有**。起身只有一个作用：如果用户正在做「每坐 90 分钟起身一次」实验，它会自动计入实验数据 |
| 频率 | 每天最多 2 次；两次至少间隔 2 小时；［今天别提醒了］当天不再出现 |
| 不出现的时候 | 最近 10 秒内有键盘输入；不在「我的白天」时段内；安静时段（见下）；用户在设置里关闭 |
| 我的白天 | 用户自设提醒时段，**首次开启时就问**（「你通常几点开始、几点结束一天的工作？」），允许跨午夜（例如 13:00–02:00）；没回答时默认 9:00–22:00 |
| 安静时段 | 已连接日历里有会议时；用户打开 DSH 顶栏的「演示模式」时。此时 LongPi 的所有提示、右侧健康栏的内容、拆包动画全部隐藏，健康栏只显示「演示模式中」 |
| 样式 | DSH 原生：13 px 文字、DSH 次级按钮；不用像素风，没有红点、动画和声音，不抢焦点 |

### 2.1 揭晓通知

- 实验可以揭晓、或复查包到了的那一天，同一个提示位出现一次：「有一张实验卡可以翻了。」［去看］［稍后］。
- 规则和起身提醒相同（不在打字时、不在安静时段、不在「我的白天」以外），每天最多一次，不计入起身提醒的 2 次。
- ［稍后］之后第二天再提示一次，然后不再提示；卡一直留着，不过期。
- 文字里不写结果，也不写指标名，在大屏上被人看见也没关系。
- 实验进行中，健康栏里有一行进度（「饭后走 10 分钟 · 第 9/14 天」），只显示做到的天数，不显示中途结果。中途看结果会影响判断。

### 2.2 健康栏默认不露数字

浏览器无法知道系统是否在共享屏幕；临时会议也不在日历上，而用户会忘了点演示模式。所以：
- DSH 右侧的健康栏和 LongPi 在对话旁的所有面板，**默认不显示任何个人数字、指标名和诊断词**，只显示「今天的实验：第 9/14 天」这类中性信息。
- 点［显示］后展开数字，60 秒后自动收起；切换工作区或窗口失去焦点时立即收起。
- 健康页本身（侧栏「健康」入口打开的完整页面）照常显示，因为那是用户主动打开的。
- 如果 DSH 将来的桌面外壳能提供屏幕共享状态，就用它自动进入演示模式；在此之前，以上规则就是默认行为。

同时取消或改为默认关闭的：
- 18:00 后「今天还有 N 项未打卡」的胶囊：默认关闭，有人说它「一股钉钉考勤味」。
- 发到飞书、企业微信、钉钉的提醒：默认不发。复测提醒只发用户自选时间的桌面通知。
- 任何「连续记录要断了」类催促、红点角标、深夜推送疾病或死亡相关内容。

实现要点：
- agent 回合状态：服务端监听 `agent/turn-start`（如果没有这个事件，用 `agent/pre-step` 首次触发代替）和 `agent/turn-stopping`，客户端 `turnBusy()` 作为兜底。
- 久坐与起身：通过 Mirobody 读取手环的分钟级步数或久坐时段。
- 会议：读 `src/calendar.ts` 已有的日历连接。
- 「演示模式」是必需的手动开关，在 DSH 顶栏和快捷键里各放一个入口；2.2 的默认不露数字是兜底。

## 3. 图鉴的结构

```
图书馆（169 张研究卡，随时读） ──翻到用到某种动物的研究──► 物种志（9 种）
        │ 提供「为什么」
        ▼
实验包（三选一） ──► 做实验（14 天，自动记录） ──► 揭晓（实验卡翻面；超出平时波动时变镭射版）
        ▲                                              │
        └──────────── 做完一个，再拿一个实验包 ◄────────┘

本人复查 / 补检查 ──► 复查包 ──► 翻开新的结果卡（和上次比：超出平时波动 / 在平时波动内）
做到某件事（含陪家人复查） ──► 足迹卡
```

### 3.1 图书馆

- 方法库里每项研究一张研究卡，按 8 章（身体的钟、器官与代谢、大脑与心理、免疫与炎症、细胞的维修、组织与再生、生殖与基因、寿命与节律）浏览，可按证据颜色筛选。
- 随时可读，不用抽，不用解锁。读过的卡角上盖蓝章，每章显示「读过 12/26」，作为阅读记录，不发奖励。
- 第一次读到用到某种动物的研究时，「遇见」这种动物，收进物种志（小鼠、线虫、果蝇、绿松石鳉、斑马鱼、涡虫、袖蝶、裸鼹鼠、弓头鲸）。物种只来自方法库里真实用到它的研究。
- 和用户有关的研究卡显示「和你的关系」一栏（见 6.3）；没有个人内容时这一栏不显示。

### 3.2 实验（主线）

**赛季**：默认 8 周，也可以设成「到下次复查为止」。一个赛季做 2–4 个实验。

**实验包（三选一）**：赛季开始时拿到一个，之后每做完一个实验再拿一个。
- 拆开是 3 张实验卡，从实验目录里按以下顺序筛选：符合安全规则 → 有可用的数据来测结果 → 和用户方案或健康页「下一步」有关 → 上季没做过。随机只决定同等条件下出现哪 3 张。
- 选一张开始；另外两张放进「待选」，下次可以直接选。也可以都不选，包留着。
- 开始前问 1–2 个和这个实验有关的问题（「常上夜班吗？」「夜里要起夜吗？」「有血糖仪吗？」）。做不到的实验换成能做到的版本，比如夜尿的人做「睡眠多 30 分钟」时改为「固定上床时间」。
- 同时最多进行 2 个实验。

**做实验**：
- 实验期 14 天；对照期是开始前的 14 天，用已有数据，不需要用户额外做什么。
- 记录全部自动：手环（步数、睡眠、静息心率、心率变异性、久坐）、家庭血压、体重，以及一键打卡。打卡只用于手环测不到的行为，比如「少放一勺盐」。
- 断几天没关系：有效天数 ≥ 10 天就能揭晓；不够时自动顺延，最多再延 7 天。仍然不够就显示「数据不够，没法判断」，**不算失败**，不扣任何东西。

**主要结果**：每个实验在开始前定好**一个主要结果**，另有最多两个「顺便看」。卡面判定和镭射版只看主要结果；「顺便看」只列出来，不参与判定。这样避免同时看很多指标、总有一个碰巧超出。

**做到情况和结果分开**：「14 天里做到了 12 天」是做到情况，单独一行；结果永远是另一个指标。例如「饭后走路」不拿步数当结果，「每坐 90 分钟起身」不拿久坐时长当结果。

**揭晓**：实验卡翻面（像素翻牌动画）：
- 写法：「主要结果 · 晚间静息心率：64 → 61 次/分，超出你的平时波动。」「顺便看 · 体重：58.2 → 57.9 公斤，在平时波动内。」只用三种说法：**超出平时波动**、**在平时波动内**、**数据不够**。不说「真实变化」「有效」，也不说是实验带来的。
- 「怎么算的」可以展开，用一句话写清：「你开始前两周，晚间静息心率每天上下浮动约 2 次/分；这两周的平均比之前低 3 次/分，超过了按你自己的浮动算出来的范围。」
- 判定：化验、血压、体重用 `data/biological_variation.json` 的参考变化值，沿用 `src/evaluate.ts`。手环指标（静息心率、心率变异性、睡眠时长、入睡时间规律性、夜间醒来次数）用这个人自己对照期的日间变异，沿用 `src/science/nof1-model.ts` 的 `posteriorDiff`（双样本 t），并为每个指标设一个最小有意义差值（例如静息心率 2 次/分）。
- 主要结果超出平时波动时卡变成镭射版；在波动内或数据不够时只翻面，同样收进「我的牌组」。同一个实验可以再做一次，牌组里保留每次的结果。

**随机版**：适合按天开关的实验（饭后走路、睡前少喝水、晚饭提前）提供「随机版」。每天早上由 LongPi 随机决定今天做还是不做，两种日子各 7 天，然后比较两种日子的结果。比前后比较更能排除季节和工作量的影响。三选一时标注「可选随机版」，揭晓时注明是哪一版。

**实验目录（首批）**：

| 实验 | 做什么 | 主要结果（顺便看） | 适用条件 / 替代版本 | 来源 |
| --- | --- | --- | --- | --- |
| 饭后走 10 分钟 | 午饭或晚饭后走 10 分钟，手环识别 | 有血糖仪：餐后 1 小时血糖；否则晚间静息心率（体重） | 可选随机版 | 方案 |

| 早晚量血压 | 每天早晚各量一次家庭血压；吃食堂外卖的人选少盐菜、不喝汤 | 家庭血压均值 | 需要家庭血压计；服降压药者照常可做 | 方案；研究卡「中国人自己的心血管风险公式」 |
| 戒掉含糖饮料 | 两周不喝奶茶、可乐等含糖饮料，一键打卡 | 体重（腰围）；尿酸、甘油三酯在下次复查时由复查包补上 | 无 | 方案 |
| 晚饭提前 | 晚饭离睡觉至少 3 小时，记录晚饭时间 | 夜间静息心率（睡眠、体重） | 用降糖药或胰岛素者不出现；可选随机版 | 方案；研究卡「什么时候吃，也算数」（小鼠，仅作背景） |
| 8 周降脂饮食 | 每天一份燕麦或豆类，用坚果替代零食，少吃肥肉和油炸 | LDL 胆固醇，由复查包揭晓 | 只在 8–12 周内有复查时出现；服他汀者也可做 | 方案 |

长实验（如「8 周降脂饮食」）的结果靠化验，所以在复查包里揭晓，实验卡上显示「等复查」。

实验目录是一个独立的数据文件，后续可以继续扩充。新增实验要满足：
1. 属于一般健康建议范围内的生活方式。
2. 有可自动获取的结果指标。
3. 写明适用条件和禁用条件。

**安全规则**（只拦截真正有关的组合，不一刀切）：
- 健康页有「先看医生」的发现时，和这个发现相关的实验不出现；先完成就医这一步。无关的实验照常出现。
- 不出现断食、大幅减重目标、补剂、药物或剂量调整。
- 用降糖药或胰岛素的人，不出现改变进食时间的实验（低血糖风险）。用降压药的人照常可以做量血压和其他实验。
- 孕期：所有实验都不出现，图书馆照常可读。未满 18 岁：图鉴整体关闭（与现有隐私规则一致）。

### 3.3 复查包与结果卡

- 本人复查、补检查之后，新的化验或体检进入 Mirobody 时，得到一个复查包。
- 翻开是这次能算出的结果卡，例如表型年龄、eGFR、十年心血管风险、软尺体脂、腰围身高比。每张写明和上次相比是否超出平时波动（用参考变化值判断）。第一次有结果时只写本次数值。
- 需要先看医生的结果**不放进复查包**，由健康页单独、认真地呈现。复查包里也不放「风险升高」这类负面结果的庆祝动效：这类卡用普通翻面，没有金光和碎片。
- 模型不适用时**不出数**，只写原因。例如 China-PAR 由 35–74 岁、没有动脉粥样硬化性心血管病的人群推导：给 80 岁的家人、或已有冠心病的人，结果卡写「这个公式不适用：超出建模年龄」或「已有冠心病，风险评估请以医生为准」，不显示百分比。只放一个小注不够，老人只会记住那个数。

### 3.4 足迹卡

做到某件事时收录：第一次带简报就诊、按时复测、补上一项检查、完成第一个实验、走完一个赛季、陪家人复查（含为家人录入并带简报就诊）。「只记你做了什么，不代表指标好坏」这句话只在足迹页顶部写一次，不在每张卡上重复。足迹卡不发卡包，收录时没有动效，只在足迹页里出现，不做成小红花。

### 3.5 节奏和不做的事

- 一个赛季大约拿到 4–6 个包：1 个开季实验包、每个实验结束后 1 个实验包、复查时 1 个复查包。每个包都对应一件真实发生的事。
- 取消：日常袋、就诊袋、目标袋，每天的卡包上限、每周上限、连续打卡，「连续记录冻结」，按章收集研究卡，研究卡抽卡，「算过」红章。新增的镭射版只用于完成的实验。
- 保留：三选一的仪式感、翻牌揭晓、物种遇见、足迹卡、像素美术。

## 4. 证据等级与颜色

| 颜色 | 含义 | 判定 |
| --- | --- | --- |
| 铜 | 细胞实验 | 主结论来自细胞、类器官或体外实验 |
| 银 | 动物实验 | 主结论来自动物实验，包括主体是动物、只附带少量人体数据的研究 |
| 紫 | 人群研究 | 队列、病例对照、横断面、量表与公式研究，以及**随机试验的事后分析或二次分析** |
| 金 | 人体随机试验 | 结论是随机对照试验**预先设定的主要结局** |

- **颜色跟着「一句话」里的主结论走**：一张卡只有一个主结论，写在「一句话」里；正文里不同等级的发现要各自标明对象（例如「补充实验在线虫和老年小鼠里做」）。
- 方法库的 `evidence` 字段只是初值。内容文件里每张卡要有 `tier` 和 `tier_reason`，两者不一致时以内容文件为准，并在方法库提 issue。
- 按此标准，当前版本金卡只有 1 张，即烟酰胺核糖与慢阻肺气道炎症（主要结局为 IL-8）。模拟断食、CALERIE、司美格鲁肽三张降为紫，并在一句话里写明「二次分析」或「事后分析」。巨噬细胞吸钙那张降为银。葫芦巴碱那张：一句话写人群关联时为紫；写补充效果时为银（补充实验在线虫和小鼠里做），二选一，由审核决定。
- **颜色只是证据标签，不是稀有度**。金卡没有扫光、闪点等「稀有」效果，和其他颜色用同一套边框做法；图书馆默认按「和你有关」排序，不按颜色。原因：唯一的金卡讲慢阻肺患者的痰，第三轮 6 人里 5 人觉得「最高级的卡离长寿最远」，金色被读成「最靠谱」。
- 图书馆的筛选栏写一句：「颜色表示研究是怎么做的，不表示和你多相关。长寿领域的人体随机试验本来就少。」

## 5. 视觉设计：像素风

风格方向参考像素卡牌游戏（如《小丑牌》）的观感，但所有图案、配色和字体都是自己的，不使用任何游戏素材。像素风只用于图鉴容器内部；健康页上的图鉴入口和起身提醒用 DSH 原生样式。图鉴页固定深色。

### 5.1 卡面是一张像素图

- 每张卡面是一张 **50 × 70** 的像素图：外轮廓、三像素边框（左上亮右下暗）、40 × 32 的版画窗、证据格、标题条，都在同一套网格上。按整数倍放大显示（`image-rendering: pixelated`）：图鉴册 3 倍（150 × 210），列表与三选一 4 倍（200 × 280），揭晓与大图 6 倍（300 × 420）。
- 文字用 HTML 叠在格子上，位置按「卡面像素 × 倍数」计算。
- 字体：**Fusion Pixel 12px**（TakWolf，SIL OFL 1.1，含简体中文），只用 12、24、36 px。生产版按图鉴实际用字做子集（全量 666 KB，子集约 100 KB），随包附带 OFL。
- 实现：`preview/codex/art.js` 是一个约 300 行的光栅小库（点、线、圆、椭圆、多边形、四邻域描边、拼合），在浏览器里用 canvas 画成 PNG 并缓存，不需要图片文件。生产版移入 `src/client/engage/art.ts`。

### 5.2 卡的种类与样子

| 卡 | 边框 | 版画窗 | 底部 |
| --- | --- | --- | --- |
| 研究卡 | 铜 `#c8703a` / 银 `#a9b6c1` / 紫 `#8a5cd6` / 金 `#f2b53a`（各带亮暗两色） | 本章像素母题，按卡号生成 | 证据格 + 标题条 + 对象与年份 |
| 实验卡 | 青绿 `#2a9d8f`（亮 `#6fd3c4`、暗 `#1b6159`） | 实验图标（鞋、闹钟、月亮、椅子、血压计、杯子、碗） | 14 格进度条：做到的天亮起，断的天留空 |
| 实验卡·揭晓后 | 主要结果超出平时波动时叠加镭射层（`mix-blend-mode: color`，阶梯动画）；否则不叠加 | 同上，加结果印章：红色「超出波动」或灰色「波动内」「数据不够」 | 结果摘要一行 |
| 结果卡 | 证据颜色（来自对应研究） | 指标的像素图形（表盘、肾、心） | 本次数值；和上次比的判定 |
| 物种卡 | 深色 `#3a372f`，星空底 | 像素小动物 | 对数寿命尺（一周到三百年，金点是这种动物，白线是人） |
| 足迹卡 | 牛皮纸 `#c9925a` | 图标 + 邮戳圈 | 日期 |
| 卡背 | 青色菱格 + π | — | — |

研究卡的八种母题（40 × 32，按卡号生成，最后统一描一圈 1 像素黑边）：表盘（身体的钟）、器官等高线（器官与代谢）、神经元（大脑与心理）、免疫细胞（免疫与炎症）、线粒体（细胞的维修）、肌纤维（组织与再生）、双螺旋（生殖与基因）、生存曲线（寿命与节律）。每章一套五色，色值见 `art.js` 的 `CHAPTERS`。

卡面只放图、编号、证据宝石、标题条和对象年份；说明放在旁边的**信息框**：深色框，24 px 标题，奶白说明框里物种名、数字、「随机」三类词着色，下面是证据和章节标签。鼠标停在卡上出现，点开显示全文。

### 5.3 包

- **实验包**：橙色 `#ef8a2a`，上下锯齿封口，腰封深色，中间三张卡的图标。
- **复查包**：紫色 `#8a5cd6`，金色腰封，简报夹图标。
- 两种包都是 30 × 42 的像素图。包装只表示来路，不暗示里面是什么。

### 5.4 动效

| 时刻 | 动效 |
| --- | --- |
| 拆实验包 | 包待机浮动 → 点击后抖动 0.5 s → 炸出像素碎片 → 三张卡背朝上依次发出，每张间隔 0.12 s → 依次翻面，每张间隔 0.16 s |
| 选中一张 | 另外两张下沉变暗，飞进「待选」 |
| 实验进行中 | 进度条每天亮一格，没有其他动效 |
| 揭晓 | 实验卡翻面 0.38 s；主要结果「超出平时波动」时多一次碎片和镭射层；「在平时波动内」或「数据不够」时只翻面，没有庆祝效果 |
| 复查包 | 和实验包相同的开包；负面结果只普通翻面 |
| 鼠标停在卡上 | 卡向鼠标倾斜（X ±9°、Y ±11°）并上浮，高光跟随，离开时回弹 |

全部用阶梯缓动或整数位移。没有声音。拆开前不暗示结果。`prefers-reduced-motion` 下关闭抖动、碎片、倾斜、浮动和镭射，只保留翻面结果。演示模式下不播放任何动效。研究卡（包括金卡）没有常驻扫光或闪点。

**简洁模式**：设置里一个开关。打开后图鉴以列表显示，不翻牌、不镭射、不碎片，内容不变。给「像素卡对我是减分项」的用户（第三轮陈国栋）。

**分享图**：实验卡和研究卡可以导出像素卡面图片。默认隐藏所有个人数字，只保留实验名、天数和「超出平时波动 / 在平时波动内」；用户勾选后才带上数字。

### 5.5 界面框架与无障碍

- 界面：面板 `#26343a`，4 px 黑色阶梯描边，下方投影；按钮按用途分色，带 4 px 下沿。背景是 192 × 108 的低分辨率墨绿旋涡，配有序抖动、扫描线和暗角。
- 无障碍：卡片是 `role="button"`；颜色之外永远有文字；键盘可操作。对比度：标题条 13.5:1，卡纸上的文字 5.5–7.1:1，信息框正文 12.9:1，着色关键词 5.7–6.1:1，面板说明文字 5.1:1。
- 和 DSH 设计规范的关系：这是 `docs/design-system.md` 里「安静、克制」的有意例外，只限图鉴容器。所有色值放在 `src/client/styles/codex.ts` 顶部的 `--lp-codex-*` 变量里。

## 6. 文案规范

### 6.1 原则

1. **客观转述研究**：谁、做了什么、发现了什么。不在句尾接否定或免责（不写「但这不代表你……」「不等于在人身上成立」这类话）。证据颜色和对象标签已经说明了是什么研究。
2. **关键限定写进「一句话」**：卡面默认只显示标题和一句话，所以物种、事后分析、只统计完成者、自报还是测量这类限定，必须在一句话里。反例：「把饭集中在夜里吃的小鼠活得最久」被读成「吃夜宵有理」；正例：「在夜里（小鼠醒着的时候）吃饭的小鼠活得最久」。
3. **标题可以有梗，但不能误导**。好例子：「两百岁也要勤打补丁」「同一管血，测出两个岁数」「血管里有个内鬼」。反例：「鼠鼠的夜宵哲学」。
4. **正文用白话**，两三句：研究怎么做的、看到了什么、一个具体数字。不照搬摘要，不出现脚本名、包名、系数名、「个人报告」「照录」「交来的」「这个人」等内部用语。
5. **阴性结果照写**（「PhenoAge 和 GrimAge 没有变化」），被用户评价为「不吹」。标题也不能只挑好听的那一半。反例：「少吃两年，老得慢一点」，三个时钟里两个没变；正例：「少吃两年，三个时钟只有一个变慢」。
6. **数字只用核实过的**：来自 `references/claims.md` 或论文正文；写不出出处的数字不写。
7. **数字要有参照**：「慢了 2–3%」要说明这是什么尺度、大约相当于什么；说不清就不写这个数字。「一项临床生物年龄」要写出是哪一项（如「一种用 7 项化验算的生物年龄」）。
8. **一句话和正文里不出现没解释的缩写**（DunedinPACE、AEP、NAMPT、IL-8 这类）。第一次出现时用中文说它是什么，或者把它移到出处和详情里。
9. **关联写成关联**：横断面和队列研究用「……的人更常见」「……的人偏大」，不用「睡少了老」这种因果句式。关联研究不作为实验的依据。
10. **利益冲突照写**：论文声明作者与相关产品有利益关系时，在出处一行写明（例如「通讯作者是这款断食餐公司的创始人」）。
11. 不写「逆龄」「年轻了」「逆转你的」「你的风险」「保证有效」「治愈」；健康数字不用于庆祝；不出现购买链接、品牌推荐和补剂建议。

### 6.2 卡的字段

| 字段 | 长度 | 说明 |
| --- | --- | --- |
| 标题 | ≤ 12 字宽（拉丁字母算半个） | 说这项研究是什么 |
| 一句话 | ≤ 45 字宽 | 主结论加关键限定，决定颜色 |
| 这项研究 | 2–3 句，≤ 120 字 | 白话 |
| 和你的关系 | 一句，可空 | 见 6.3 |
| 出处 | 第一作者、期刊、年份、DOI | 预印本标「预印本」；一键打开 DOI 或 PubMed |

### 6.3 「和你的关系」

只在有具体内容时显示，三种情况：
1. **你的结果**：「按你在档案里填的平时睡眠（6.5 小时），你在『6–8 小时』那一组。论文用的也是自报时长。」测量口径必须和论文一致：论文用自报，就用档案里的自报，不用手环。
2. **下一步能做什么**：「你的腰围身高比是 0.49。再量一次颈围和臀围，就能算出体脂率。」
3. **和你已有功能的联系**：「健康页上的『十年心血管风险』就是用这个公式算的。」

需要研究用检测（甲基化、大规模血浆蛋白组等）的卡，这一栏**不显示**。

### 6.4 生产与审核流程（后续 session）

1. 每章由一个写作子代理按本规范，从 `skill.json` 和 `references/claims.md` 写出全部字段，并给出 `tier` 和 `tier_reason`。
2. 每章再由一个审核子代理以生物医学研究者的身份逐张核对：数字是否有出处、颜色是否符合第 4 节、限定条件是否在一句话里、有没有内部用语和否定尾巴。审核结果写回内容文件，记录 `review: { by, at, issues }`。
3. 构建脚本把关：
   - 没有通过审核的卡不进图书馆，列为「待上架」。
   - 文案自动检查禁用词、内部用语、否定尾巴（如「不等于」「并非你」「不是你的」）、字数，以及空的「和你的关系」。
4. 第一轮的 24 张样例里有 4 处科学错误，第三轮又挑出 5 处问题：关联写成因果、颜色和主结论不符、标题只挑好听的一半、缩写没解释、利益冲突没写。所以审核不能省。第三轮材料 `docs/usertest/round3/brief.md` 里的 12 张研究卡可以作为文案起点，但要先按 6.1 第 5、7–10 条修过：「少吃两年」「睡少了老」「假装饿了五天」「血管里有个内鬼」「咖啡里的那种分子」这几张都需要改。

## 8. 验证方法：用户模拟

每次迭代玩法或文案后，按同样的方法再测一轮：
1. 写一份 `brief.md`，只包含用户在产品里能看到的东西（规则原文、卡片原文、界面行为），不写设计理由和模拟结论。
2. 6 个人设（第 1 节），每轮用新的子代理，后台并行运行，互相不可见，不读其他轮的材料。
3. 统一问题：
   - 第一眼印象。
   - 一个工作日的时间线。
   - 第 1、3、8 周还在不在用。
   - 好玩和烦人的点。
   - 行为有没有改变。
   - 文案逐句点评。
   - 工作中的出现方式能不能接受。
   - 最想改的 3 件事。
   - 唯一会让你关掉它的理由。
   - 四项打分。
4. 下一版的目标：「会坚持两个月」平均 ≥ 5，「有用」平均 ≥ 5.5，没有人设在「坚持」上低于 3；没有人再提到「做了不验证」「投屏露出」「看了等于没看」「真实变化承诺过头」「揭晓了不知道」。第三轮（定稿 1.0）为坚持 4.3、有用 5.3，最低坚持 3；1.1 的修订针对的就是这几项，实现后的第一件事是按本节再测一轮。
5. 子代理的截图附件传不过去，需要看图时在任务里让它们自己用 Read 工具打开截图文件。
6. 模拟用户是代理，不是真人。它能有效找出规则漏洞、文案问题和明显的使用障碍，但不能代替真实用户的留存数据。实现上线后，应该用真实的匿名使用指标来核对，例如揭晓的打开率、实验完成率、起身提醒的确认率。

## 9. 待定问题

1. 没有手环的人，起身提醒和多数实验都做不了，要不要为他们设计「只用打卡」的实验，以及怎么防止刷数据。
2. 「好玩」在第三轮降到 4.8。两次揭晓之间要不要加一点不靠运气、不靠刷的内容，比如每周一次两分钟的「证据鉴定」小测：给一个常见健康说法，用图书馆里的卡判断证据等级。这类内容要在下一轮模拟里先单独测，不能直接加。
3. 图书馆全部开放后，物种志半小时就能集齐，收集感弱（阿May、李子轩）。要不要把物种和「做完相关实验」挂钩，而不是和「读到」挂钩。
4. 赛季结束时要不要有一页「赛季回顾」（做了哪些实验、哪些超出平时波动），以及它和现有的赛季回顾怎么合并。
5. 方法库 `evidence` 字段和 `summary_zh` 的错误，要不要回到方法库修，而不只是在图鉴内容里覆盖。
6. DSH 桌面外壳能否提供系统级屏幕共享状态，用来自动进入演示模式。
