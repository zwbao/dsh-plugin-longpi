# LongPi UI 独立审查（2026-09-30）

截图：scratchpad/shots/png/{wide,narrow}-{总览,化验,睡眠,运动,日程,深度分析,问 LongPi}.png，wide-添加家人.png，wide-设置.png。
规范：docs/design-system.md。编号在分工里被引用。

## P0

1. 页头右上：「在看」被挤成竖排（people.ts 用了 .lp-label）；下拉框和「添加家人」比其他按钮低约 10px（.lp-actions 没有 align-items:center）。→ 标签改为不换行的小标签或去掉；控件统一 32px 高、垂直居中。
2. 添加家人：表单卡片塞进页头右侧操作区，把左侧标题挤成约 100px 宽、全部折行。→ 改为 DSH Modal，或页头下方整行面板，绝不放在操作区里。
3. 添加家人表单：字段标签离自己的输入框比离上一个输入框还远。→ 用 .lp-field > .lp-field-label + .lp-input。
4. 化验表：表头 5 列，行只有 3 块内容；「和正常波动比」「来源」列永远空；「仅 1 次」随名字长度左右漂移；「体检」挤在名字后面。原因：indicators.ts 的行同时挂了 lp-ind-btn 和 lp-move-btn，后者的 flex 覆盖了 6 列 grid。→ 删 lp-move-btn；行拆成与表头一一对应的格子，表头与行共用同一个 grid-template 变量。
5. 睡眠 / 运动：整页照搬化验界面，出现「全部 0 / 有变化 0 / 方案相关 0 / 手环 0」「最近一次体检 9 月 10 日」，空状态写「没有'全部'的指标。看全部 →」，点了回到自己，形成死循环（life.ts 直接套用 IndicatorsTab）。→ 数量为 0 时隐藏筛选栏和体检日期，换成专门的空状态：还没有睡眠数据 + 连接手环。
6. 深度分析：「现在的情况」卡片与「进行中」卡片上下贴死（.lp-section 没有 gap）。
7. 深度分析「自动深度分析」：原生复选框比文字低，下面多出 12px（用了 .lp-label；.lp-switch 被重复定义）。→ 改用 ui.ts 的 Switch。
8. 深度分析进度：11 步只是缩进的纯文本，没有状态点和进度条（误用方案页的 .lp-steps，lp-step-done 没有定义）。→ 用 .lp-progress-steps + .lp-bar。
9. 深度分析报告：iframe 固定 640px 高，有内部滚动条；报告内部是另一套视觉（米色、紫色）；边框用了未定义变量回退成 #ddd；圆角不一致。→ 做成摘要卡片 + 「打开完整报告」（在新标签页打开报告路由）；如果保留内嵌，外框与卡片一致且高度自适应。
10. 器官表 / 问题看板：浏览器默认表格，表头与内容对不齐，没有行线；「器官」列窄到一行一个字；「把握」表头拆成两行；结论单元格塞了 600 多字。→ 器官表用 .lp-table（首列 nowrap）；问题看板每题一张卡片，长文折叠。
11. 页头：状态行显示「已连上 · 52 项检查」，人员下拉框却显示「我 · 未连接」，前后矛盾。→ 统一数据来源；只有真的没连上时才显示警示标签。
12. 日程「建议，还没写上」：只有标题的空卡片。→ 没有内容时不渲染，或者显示一行空状态。

## P1

13. 二级入口「方案 / 档案 / 赛季 / 研究」：散落的灰字按钮，归属不清；选中二级页后一级标签全部失去选中态。→ 按规范 §3，做成标签行最右侧的「更多」菜单，二级页出现临时选中标签。
14. 一级标签：选中项同时有灰底和下划线两种指示。→ hover 只变文字颜色，选中只保留下划线。
15. 总览「今天」卡片：7 条任务全部加粗，每行一个黑色实心「完成」按钮，视觉太重。→ 标题改 400 字重；「完成」改描边按钮或勾选圆圈。
16. 结果卡片：「模型估计」标签有的在右上角、有的在标题下；ⓘ 位置会飘。→ 标题行只放标题和 ⓘ，标签一律放在下一行。
17. 结果卡片：「还不能计算」22px 与 40px 大数字视觉重量不一致；「这次的变化」只占半宽。→ 等待态 17px 加一行说明；落单卡片占满整行。
18. 「还需要」标签用虚线框，「等 6 项」含义不清。→ 用实心中性标签，写「还差 N 项」，只显示前 3 个。
19. 结果正文露出英文字段名和单位写法：「sleepDuration 5.6 h」「umol/L」「kg/m2」；0.6 与 0.56 精度不一致；标题与正文第一句重复。→ 格式化层统一处理。
20. 化验行：每行 3 行高约 83px，51 项拉出 4000px 以上；「体检」每行重复；同一指标因有没有英文缩写被拆成两行。→ 单行 48px 表格行，来源放独立一列（同名合并属数据层，另行处理）。
21. 化验「仅 1 次」：11px、#adb2b8，对比度约 2.1:1。→ 12px ink-3，或者直接显示「—」。
22. 筛选：计数为 0 的项仍可点；计数 11px 且透明度 0.65。→ 用分段控件，计数 12px ink-3，为 0 时置灰。
23. 日程 / 问 LongPi：卡片标题和标签页名重复；只有深度分析一页有「眉题 + h2」页头。→ 所有标签页都不设页头，直接从卡片开始。
24. 问 LongPi 推荐问题：看起来像输入框；和 .lp-prompt、.lp-quest-card 是三套重复实现。→ 统一用 .lp-row-btn（右侧箭头，hover 加底色）。
25. 日程：同一页三种空状态。→ 统一用 .lp-empty。
26. 深度分析介绍段一行约 68 字；token 成本提醒是普通浅灰字。→ 正文最大宽度 40em；成本提醒用 .lp-callout-warn。
27. 设置页：提醒开关是绿色 switch，「一起研究」却是「开着 / 关掉」两个按钮；折叠区用浏览器原生三角。→ 都用 Switch；折叠区用 base 里的 details 样式。
28. 设置页：悬空的一行浅灰字；「下次：打卡 … · 复测 … · 小结 …」挤成一长串。→ 前者用 .lp-callout-info，后者用 .lp-kv。
29. 全局重复定义：.lp-field、.lp-input、.lp-switch、.lp-item-foot；未定义变量 --lp-line、--lp-soft 回退成 #ddd。（base 已处理，剩余由各模块清理）
30. 90 多个类名在组件里用了、CSS 里没定义（见 test/css-classes.mjs 的输出）。
31. 引导：.lp-steps 撞名（已改为 .lp-stepper）；新类名缺少样式（base 已补 lp-callout / checkrow / form-grid / seg-item / textbtn / upload-simple / bullets / stepper，还缺 onb-text、onb-actions、stepper-label）。

## P2

32. 眉题显示版本号「LongPi 0.7.0 · 健康」。→ 去掉版本号。
33. 引导横幅用浅蓝底，而且靠 margin:-12px 上拉。→ well 底色，页头下方 16px。
34. 箭头有粗箭头、细箭头、chevron 三种。→ 统一用 chevron 或 →。
35. 「本周」周格子：20px 格子配 10px 字，对比度低；后面那句提示的前导点号多余。→ 22px 格子、12px 字，提示放到下一行。
36. 卡片阴影：0.5px 描边环加两层柔影，和 DSH 偏扁平的风格不一致。→ 1px 描边、无阴影（base 已改）；lp-rise 入场动画删除。
37. 页脚两行免责和深度分析的边界说明重复。→ 合并成一行。
38. 窄屏页头：操作按钮和状态行挤在一起。→ 间距 20px，操作按钮单独一行、两端对齐。
39. 结果卡片的「查看加测清单」按钮上方有约 80px 空白。→ 「还需要」标签和按钮放在一起、一起贴底。
40. 设置页隐私区单独用了 28px 的灰色图标方块。→ 去掉，或全局统一。
