# 王建华（58，生物信息学教授）· 第三轮

**1. 第一次看到**：像素卡牌，还是《小丑牌》风？我都58了……不过它按证据类型分铜、银、紫、金四色，这套分类倒是戳中了我这个老集邮的。

**2. 一个工作日**：8:30打开DSH，让agent跑甲基化预处理，我自己改学生论文。10点多，右下角冒出来一行"已经坐了1小时40分"。agent正跑着，我就点了［好］，去倒杯茶。其实因为前列腺，我白天很少能坐满90分钟，一周也碰不上几次这个提醒。等agent的时候翻几张研究卡，主要是挑错。下午开组会，它自动隐藏了，这点好。晚上看看我妈的数据。

**3. 第1、3、8周**：第1周天天翻，一张张核DOI。第3周图书馆基本不开了，只等揭晓。第8周实验在后台自己跑，只有揭晓那天才点开。

**4. 实验**：三选一我选"饭后走10分钟"，因为我血糖偏高，家里有血糖仪。揭晓确实让人有点盼头，但方法上我不服：
- 拿前两周和后两周比，没有随机，季节、工作量、回归均值全混在里面。
- 一次看三四个指标，总会有一个碰巧"超出波动"，可阈值怎么算的也不说。
- 饭后走明明可以按天掷硬币决定走不走，那才算像样的n-of-1。
- "每坐90分钟起身"拿"久坐时长"当结果，等于是在量你做没做，和它自己"不看做没做"的说法矛盾。
我真正烦的是起夜，实验包里偏偏没有"睡前少喝水"这种。

**5. 行为改变**：午饭后绕湖走一圈，一周三四次。但推动我的是血糖仪上的数，不是卡。陪我妈复查我本来就会去，为这个发我一张足迹卡，有点像幼儿园发小红花。

**6. 卡片文字**：
- "超出你的正常波动（真实变化）"：超出波动不等于是走路造成的，括号里那四个字承诺过头了。
- "睡少了老，睡多了也老"：横断面的关联写成了因果，睡得多常常是先有病。还拿它当"多睡30分钟"实验的依据，说不过去。
- "咖啡里的那种分子"标紫色：人群部分只是关联，补充的效果全是在线虫和小鼠里做的，按它自己的规则该是银卡。
- "80岁的家人也能算，结果旁会写明超出了建模年龄"：China-PAR建模用的是35–74岁的人，超出就别出数。我妈只会记住那个数，旁边的小注她不会看。
- 唯一一张金卡讲的是慢阻肺痰液里的IL-8，离长寿挺远，金色很容易被读成"最靠谱"。
- 写得不错的："同一管血，测出两个岁数"很诚实；"这个数字只统计了做完试验的人"，还有CALERIE那张老实写了"PhenoAge和GrimAge没变"，都不吹。整体读着顺，就是标题有点标题党。

**7. 能不能接受**：一天最多两次、不弹窗、开会自动隐藏，我能接受。要是在学生面前冒出我的健康数字，或者推到飞书上，我立刻关。

**8. 最想改的3件事**：1. 公开"正常波动"的阈值怎么算，把"真实变化"改成"超出波动"，再加一个按天随机的实验选项。2. 卡的颜色按支撑结论的那部分证据来定。3. 超出模型年龄就不出数；加针对起夜和老人的实验。

**9. 关掉它的理由**：如果它继续把"超出波动"叫成"真实变化"，那就是拿科学的样子讲故事，我会关掉。

**10. 打分**：好玩 5（有收集的味道，但两个月也就几张镭射卡）· 有用 5（真正改变我的是血糖仪，不是图鉴）· 坚持两个月 6（不用打卡，挂着也不费事）· 推荐 4（同事看到第一反应是截图挑错）
