# 李子轩（24，应届全栈，网络梗原住民）· 第三轮

**1. 第一眼**：小丑牌皮肤的 PubMed？有点东西。结果全图鉴唯一一张金卡，讲的是慢阻肺患者的痰。就这？

**2. 一个工作日**：10:30 开 DSH，让 agent 跑重构。12:00 下楼拿外卖，外卖成了我唯一的运动。15:00 等 agent 跑测试，右下角冒出「起来走两分钟？」，我点［好］去接水，顺手下单一杯奶茶。22:00 下班它也收工。一天最多两次，不烦。

**3. 第 1、3、8 周**：第 1 周最上头：一晚刷完 169 张标题，物种志半小时集齐，弓头鲸截图甩群里。第 3 周第一个实验揭晓完，第二个开了，然后「你什么都不用点」，那我就真不点了。第 8 周只剩起身提醒还活着。复查包？体检一年一次，无缘。

**4. 好玩和烦的**：翻牌、镭射、物种志好玩。三选一我吃，系统果然给我塞了「戒掉含糖饮料」，永远留着不选，何况尿酸得等一年后复查才揭晓。「同一时间起床，周末也一样」？周末睡到 12 点是我最后的尊严。我选最好白嫖的「每坐 90 分钟起身一次」，反正提醒本来就在推，挂机领卡。最烦是揭晓：24 岁没毛病，大概率一排「在你的正常波动之内」，镭射卡里装着空气。

**5. 改变了啥**：起身多了；外卖奶茶一杯没少，觉也没早睡。挡住它的是加班，还有静息心率 64 变 61 我根本感觉不到。

**6. 卡片文字**：别扭的：「一项临床生物年龄的中位数下降了约 2.5 岁」：读三遍才懂。「DunedinPACE 变慢了，PhenoAge 和 GrimAge 没变」：字母汤，看了等于没看。「剪断它的酶叫 AEP，被剪的是 NAMPT」：标题说「内鬼」，点进来是生化课。「只记你做了什么，不代表指标好坏」：像免责声明。不错的：「两百岁也要勤打补丁」，程序员狂喜；「同一管血，测出两个岁数」，劝你别迷信数字，反而最好玩；起身提醒那句也没爹味。整体是标题小红书、正文知网。改两张：**弓头鲸：活两百年，全靠 hotfix 打得勤**：修 DNA 又快又准，靠一个越冷越多的蛋白 CIRBP。塞给果蝇，果蝇也续上了。**少吃两年，三个时钟只有一个点头**：一个说你老得慢了 2–3%，另外俩已读不回。

**7. 放在工作里**：能接受，不弹窗不出声，开会自动藏，这点满分。会立刻关的情况：投屏时漏出体重；推到飞书；哪天它对我的奶茶说「建议减少」。

**8. 最想改**：① 正文说人话，术语收进点开以后；② 「没变化」也得有乐子，实验中间给点能看的；③ 出个隐藏个人数字的分享版，想甩群又不想晒体重。

**9. 一个理由**：不是卸载，是忘了：三周后它只剩一个手环自带的久坐提醒。

**10. 打分**：好玩 6（前两周真香，后面没东西玩）· 有用 4（只改了起身这一件事）· 坚持两个月 3（图鉴本体活不到第 8 周）· 推荐 5（推荐卡名，不推荐养生）
