# 陈国栋（46，技术总监，高血压）· 第三轮

**1. 第一次看到**：像素卡牌、翻牌动画，我都 46 了，还给我发卡？翻到「金卡目前只有 1 张」的时候愣了一下：行，至少没吹。

**2. 典型的一天**：9:30，让 agent 去跑 CI，我切到飞书回消息。10:00–12:00 开评审会，日历里排着，它全程不出声。好笑的是，我一天坐得最久的就是开会，偏偏这段时间它从来不提醒。14:20 切回 DSH，才看见右下角「已经坐了 1 小时 40 分」，估计早就弹出来了，我一直在飞书里没看见。点了［好］，起来去倒了杯水。16:00 临时被拉去投屏讲 code review，日历上没这个会，我也忘了点演示模式，健康栏就那么开着，还好停在一张线虫卡上。从那以后每次投屏都得先点一下，烦。

**3. 第 1、3、8 周**：第 1 周挨着看了二十来张卡的出处。第 3 周图书馆就不翻了，只剩血压实验和起身提醒。第 8 周提醒还开着，主要是它不烦人；第二个实验揭晓了，我隔了 5 天才发现。号称「主线」，自己沉底了。

**4. 好和烦**：好的：卡的颜色就是证据级别；一天最多 2 次、打字时不出来、没声音也没红点，挺克制。烦的：一吃药就让「先问医生」。我吃氨氯地平，难道要去问医生能不能量血压？他两年前就让我量了。「做饭少放盐」也用不上，我三餐都是食堂加外卖。三选一对我没吸引力，我只想直接挑。我选了量血压，因为这是我唯一该做、又一直没做的事。揭晓我会看，但「真实变化」四个字让我皱眉：就是前后两周一比，没有对照，顶多算「超出平时波动」。

**5. 改变了什么**：早晚量了两周血压，现在只剩早上量，一周四五次，算是真改了。多走路没做到，吃完午饭就进会议室。

**6. 卡片文字**：
- 别扭：「一项临床生物年龄的中位数下降了约 2.5 岁」：到底是哪一项？还有，通讯作者是那款断食餐公司的创始人，卡上一个字没提。「少吃两年，老得慢一点」：三个时钟有两个没变，标题专挑好听的那个。「80 岁的家人也能算」：我爸已经有冠心病了，这个公式本来就不适用于已经得病的人，卡上该写明。
- 不错：「这个数字只统计了做完试验的人。」「同一管血，测出两个岁数」整张都好。「两百岁也要勤打补丁」，程序员看了会心一笑。
- 整体看，「一句话」那层读着挺顺；标题一半俏皮，一半像营销。

**7. 能不能接受**：能接受，前提是：投屏时永远不露健康内容，不往飞书推，不卖补剂。哪天出现 NMN 的购买链接，我当场关掉。

**8. 最想改的 3 件事**：① 检测到屏幕共享就自动隐藏，别靠我记得去点按钮。② 实验前没有基线数据就直说，先补两周；揭晓里的「真实变化」改成「超出平时波动，不代表是实验带来的」。③ 给一个纯列表模式，不要翻牌，也不要镭射卡。

**9. 唯一的卸载理由**：投屏的时候，被同事看到我的健康栏。

**10. 打分**：好玩 3（像素卡对我来说是减分项）· 有用 6（血压那项真起了作用，研究出处也写得老实）· 坚持两个月 5（提醒和量血压会留下，图鉴不会）· 推荐 3（健康太私人，不会在团队里推；私下可能会推给同样有高血压的老同学）
