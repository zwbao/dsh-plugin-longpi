# 陈国栋（46，技术总监，高血压）· 第二轮

**1. 第一眼**：像素卡牌加拆包动画，要我在写代码的地方集卡？……不过卡的颜色是按证据类型分的，这点我认。

**2. 一个工作日**：9:30 让 agent 去 review PR，我切到飞书回消息。11:10 跑集成测试，右下角冒出一行：「坐了 1 小时 40 分。起来走两分钟，回来正好跑完。」头几天我真起身去接水，还点了「做了」。后来就不信它了。那 90 分钟有一半我在飞书上开会，不是坐着干活。「正好跑完」它根本不知道，有时还剩 6 分钟，有时 20 秒就收起来了。更烦的是，同一个位置有时会换成「顺手拆一包」。劝我起身的地方拿来勾我拆包，味道就变了。我还经常投屏讲 code review，那行字一屋子人都看得见。午饭后本来就和同事走一圈，手环自动记上了，零成本。卡包就攒着，周末才拆。

**3. 第 1、3、8 周**：第 1 周认真翻了图书馆。结果卡开出了 eGFR 和十年心血管风险，吃降压药的人确实想看这两个。第 3 周攒了十几包没拆，起身那行基本无视。饭后走路的实验出了结果：步数的变化超出了正常波动，静息心率没变。挺老实，但也就这样。第 8 周还在用的只剩实验卡和复查前的简报。

**4. 好的和烦的**：
- 好：颜色对应证据类型。实验卡说会「区分真实变化和正常波动」，这是我留着它的理由。需要先看医生的结果不放进卡包，这个做法对。
- 烦：每天最多 2 包、最多拆 3 包，一看就是冲日活的设计。「做了」点一下就送包，全凭自觉。「假装饿了五天」卡上自己写着是二次分析，而且只算了完成试验的人，还挂金边，等于给它镀金。实验卡里没有血压，我最该盯的指标偏偏不在。

**5. 行为有没有变**：量血压的习惯没变。我早上在家量，提醒却是桌面通知，那会儿电脑还没开。真改变的只有一件事：把我爸的数据录了进去，带着简报陪他看了心内科。包不包的无所谓，简报是真好用。

**6. 卡片文字**：
- 别扭：「鼠鼠的夜宵哲学」太卖萌，还容易让人以为吃夜宵是好事。「回来正好跑完」空头承诺。「C/EBPβ 蛋白开启 AEP 酶，AEP 把 NAMPT 切断」读完不知道跟我有什么关系。「需要研究用的大规模血浆蛋白检测」图书馆里一堆这种，读了等于没读。
- 不错：「前后差几岁，可能只是测量误差。」敢说自己的局限。「实际平均做到了 12%」，不吹。「记的是你做了什么，不代表指标好坏。」
- 整体句子短、出处齐全，比养生公众号强多了。就是标题太想显得好玩。

**7. 能接受吗**：不弹窗、不出声，能接受。下面这些出现一个我就立刻关：推到飞书、出红点、投屏时露出健康数据、哪张卡写「逆龄」。

**8. 最想改的 3 件事**：
1. 实验卡加上家庭血压；China-PAR 那张卡写清楚算没算降压药和家族史。
2. 等 agent 时那一行别承诺时间，投屏时自动隐藏，也别和拆包抢同一个位置。
3. 卡面上标出「事后分析」，金边别做成稀有卡的感觉。

**9. 打分**：好玩 4（我不是它的目标用户）· 有用 6（结果卡和实验卡确实有干货）· 坚持两个月 4（卡包坚持不了，实验和复查会坚持）· 推荐 5（我会推荐 LongPi，但不推荐图鉴）
