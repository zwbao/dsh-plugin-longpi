# 林蔚（38，产品负责人）· 第一轮

（她没看到附件里的截图，下面提到截图的地方只依据材料里的文字说明。）

**第一眼**：169 张论文卡？我连体检报告都只看红字……不过 8 章进度条（01）确实有点戳我。

**一个工作日**：10 点让 agent 整理昨天三个会的纪要，等它跑的那一两分钟，是我唯一可能点开的时候。前提是早上称了体重，不然根本没包可拆。中午到四点连着开会。五点赶 PRD，让 agent 拉数据，等的时候偶尔拆一包，扫一眼一句话就关。18:00 后右下角冒出「今天还有 2 项未打卡」，有次我正投屏给老板看数据，它就在那儿亮着。晚上我不开 DSH。

**第 1 周**还在用：目标袋三选一（05）挺爽，为了拿日常袋连量了三天血压。**第 3 周**半用半不用：日常袋一周封顶 3 个，周三就拿满了，周四再量血压图鉴也不理我，那我也不量了。「读过」蓝章是点出来的，不是读出来的。**第 8 周**基本不开了：能盖红章的就软尺体脂、睡眠那几张，其余都要甲基化时钟、SomaScan，镭射版是给别人准备的。

**好玩的**：遇见弓头鲸（06），「能活两百年的哺乳动物」我能讲给儿子听。集齐一章送一次冻结，我常出差，用得上。**烦的**：它奖励的是"记了"，不是"做到"。我 LDL 高，却随机抽到线虫、cGAS–STING，「器官与代谢」那章没法先收。

**改变行为了吗**：称体重勤了三周。走路、晚饭一点没动，拆完包我还是不知道今天该吃啥。

**别扭的文字**：
- 「只把你交来的两次生物年龄相减……不从化验重算生物年龄」：我哪来两次生物年龄？满屏"只……不……"，像法务在说话。
- 「按 BioAge 包 phenoage_calc.R 的 orig=TRUE 系数计算」：这是写给我的，还是写给代码评审的？
- 「内皮 C/EBPβ–AEP 切断 NAMPT」：看了等于没看。
- 「个人报告只标出对上哪一组。」哪一组？对上了又怎样？
- 「人群里的关联不等于因果……」第三遍起眼睛自动跳过。

**不错的**：「睡太短或太长，多种生物年龄差都偏高」，看完我真想了一下自己只睡 6 小时。足迹卡那句「记的是你做了什么，不代表指标好坏」，很体贴。

**希望它怎么出现**：agent 跑超过 30 秒时，在等待区给我一行"起来走两分钟 / 量个血压"，点一下就打卡，别弹拆包动画。投屏、写文档的时候别冒头。飞书提醒我绝对不开，那是工作的地盘。

**最想改的 3 件事**：
1. 奖励跟着"做到方案"走，别按周封顶。
2. 卡片默认只给一句话，加一句"跟你有啥关系"，其余全部折叠。
3. 让我按体检问题选章节。

**打分**：好玩 5（拆包和三选一有点意思，但卡面就是论文摘要）· 有用 3（没让我更清楚该干嘛）· 坚持两个月 2（第三周就被封顶劝退了）· 推荐给同事 3（爱集卡的程序员同事也许喜欢，我不会主动推）
