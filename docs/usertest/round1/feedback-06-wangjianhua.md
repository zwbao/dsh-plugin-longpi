**第一眼**："又是抽卡？……169 张全是真论文，那我倒要看看写错了几张。"

**一个工作日**：7:30 在家量血压、测血糖，录进 LongPi，这些本来就做。8:30 开 DSH，一个工作区让 agent 跑学生的单细胞差异分析，另一个回审稿意见。agent 一跑三五分钟，第一周我会点「健康」拆一包；后来就不点了，等的时候我得盯着它别把 R 脚本改坏，没心思看裸鼹鼠。18:00 胶囊冒出来，我还在改稿，不点。真想起健康页，是周末帮母亲录血压的时候。

**第 1、3、8 周**：第 1 周天天开，职业病，挑错，顺手把 PhenoAge 那张算成了红章。第 3 周，周三就拿满 3 个日常袋，周四起懒得测；能盖红章的卡多半要甲基化、SomaScan，我都没有。第 8 周基本不开了，只在复查糖化那周拿过一次就诊袋。

**好玩和烦**：物种卡就 9 种，能集齐，最像集邮；08 把概率摆出来，算诚实。烦的：每周 3 袋上限，等于教我一周只测三天；不重复、必集齐、不能交易，集邮的乐趣是找和换，这里只剩进度条；一季四五十包，169 张得三四季才集齐；集齐一章奖励"连续记录冻结"，我又不在乎连续。最要紧的是规则里没提家人，母亲复查算不算就诊袋，我不知道。

**改变了什么**：没有。前三周多量腰围是为了刷袋。控糖、散步、前列腺复查、母亲的认知，卡片一样都不沾，奖励和我该做的事是脱节的。

**卡片文字**：
- No.163「个人报告只标出对上哪一组。」人怎么对上小鼠组？小鼠是夜行的，正文却写「夜晚进食再加一段禁食，寿命延长更多」，血糖高的人看了会去晚上吃。
- No.025「位点到齐时，个人报告用补充表的系数重算。」拿裸鼹鼠的时钟算我？
- No.079 标「紫·人群研究 · 人」，可主体是巨噬细胞实验，人这边只有一点全血表达数据。颜色标错，就是证据等级标错。
- No.030「用中国四个队列的 2 万多名成人建立」：建模用的是两个队列、两万一千人，另外两个是验证队列。
- 写得不错的：No.166「长寿线虫多出来的日子，主要是衰弱期变长」，一句话讲清了寿命和健康寿命；No.011「同一样本重测能差好几年」，这句该印在每张时钟卡上。

**在 DSH 里**：能接受的：agent 跑超过两分钟时，右侧栏安安静静一行「今天还没量血压」；复查前两周提醒一次，母亲的也提醒。会让我立刻关掉的：在 agent 输出里插拆包动画、弹窗，或者工作时间推桌面通知。DSH 是干活的地方。
