# 阿May（31，自由前端兼设计师）· 第一轮

（没收到截图附件，只依据 brief 文字。）

**第一眼**："卡包！镭射！还有弓头鲸！"拆开一张读到"按 BioAge 包 phenoage_calc.R 的 orig=TRUE 系数计算"……这不是我昨天让 agent 写的注释吗。

**一天**：11 点起床，开 DSH 让 agent 重构组件，它跑的那一两分钟我会点开图鉴，前提是今天有包。可我只有手表数据，不知道自动同步算不算"自己的记录"，家里连秤都没有。18:00 右下角冒出"今天还有 2 项未打卡"，那会儿我在跟甲方对稿，直接无视。凌晨 2 点改完 CSS 睡不着又去翻卡，刷到"预示痴呆的蛋白"，这下更睡不着了。

**第 1、3、8 周**：第 1 周天天玩，目标袋三选一挺爽。到第 3 周，周三就把每周 3 个日常袋用完了，后面几天点进去都是空的；就诊袋我不去医院就拿不到。第 8 周只在等 agent 的时候偶尔点开看看进度，一章都没集齐，169 张我看是下辈子的事了。

**好玩 / 烦**：好玩的是抽卡不重复、卡包不过期，物种卡也有意思（弓头鲸那条冷知识我截图发了小红书），足迹卡不评判人。烦的是我最想要红章镭射版，可大多数卡要甲基化时钟、SomaScan、GFAP，我一样都没有，永远只能盖蓝章。每周 3 包的上限把节奏卡死了。金卡总共就 4 张，嘴上说颜色不代表稀有度，谁信啊。

**行为改变**：只有一次：为了让"软尺量体脂"那张变成镭射版，我翻出软尺量了腰围。早睡和按时吃饭都没变，凌晨 3 点睡照样能打卡拿包，它奖励的是"记下来"，不是"做到"。体检也没去，为一张卡去挂号太远了，而且我根本不知道该查什么。

**卡片文字**：
- "AEP 又怎样在 N136 切割 NAMPT"：字我都认识，连起来就不认识了。
- "个人报告只标出对上哪一组。"：哪组？我是哪组？看了等于没看。
- "只核对你交来的SomaScan序列号……"：我从来没交过什么序列号。
- "照录这篇成纤维细胞实验的转化组合"：我又不是鲸的细胞。
- 每张卡都是"只……不……"的句式，读着像免责声明；提示语也每张一字不差，到第三张我就直接跳过了。
- 写得不错的："睡太短或太长，多种生物年龄差都偏高"，这句直接戳到我；"长寿线虫多出来的日子，主要是衰弱期变长"，让人想转发。

**在 DSH 里怎么出现**：能接受的：agent 跑超过半分钟时，角落探出一张小卡，只给一句话，我不点它就自己缩回去。会让我立刻关掉的：我打字时弹窗、飞书推送、红点角标、深夜推送痴呆或死亡风险这类内容，还有"你还没完成"那种语气。

**最想改的 3 件事**：
1. 手表的睡眠和心率直接算作记录，再多放几张靠手表、软尺或问卷就能盖红章的卡。
2. "拿你的记录能做什么"改成人话。我没这项数据时，就告诉我还差什么、怎么拿到。
3. 出像素风、可分享的卡面，一键存图。

**打分**：好玩 6（拆包挺上头，可卡上的文字劝退）· 有用 3（除了睡眠那张，基本都跟我没关系）· 坚持两个月 3（第 3 周我就开始敷衍了）· 推荐 4（会推给爱收集的朋友玩一周，但不会说它让我更健康了）
