# 周屿（27，后端工程师，玩小丑牌）· 第一轮

（没收到截图附件，涉及截图的地方按 brief 文字写。）

**第一眼**：哦，把 PubMed 做成集卡册了。金卡就 4 张，不是设计出来的稀有，是人体随机试验本来就少。

**一个工作日**：上午盯着 agent 重构、修 bug，健康页碰都不碰。下午集成测试一跑两三分钟，我切去 review 别的工作区，偶尔点开健康页看看有没有包。一般没有，因为我啥也没测。18:00 后右下角冒出「今天还有 2 项未打卡」，我还在赶需求，懒得管。凌晨 1 点打小丑牌的时候倒是想得起来，但不会为了它再开电脑。

**第 1、3、8 周**：第 1 周还在玩，目标袋三选一有点仪式感。第 3 周摸清了日常袋每周只给 3 个，于是周一到周三早上上秤拿满，后四天一条都不记，拆包就成了清红点。第 8 周基本不打开了，快复查的时候也许会为了就诊袋回来一次。

**好玩和烦人的**：我认的：不重复、169 包保底、概率公开、不收钱。拆到弓头鲸「遇见新物种」那下我笑了。烦的是完全没有决策：抽到什么跟我做了什么没关系，卡也用不了，三选一选哪篇都没后果。一个赛季撑死四十来包，一章平均 21 张，也就集齐一两章。集齐的奖励是「连续记录冻结」，可我根本不在乎连续打卡。

**行为有没有变**：唯一的变化是周一到周三早上称体重，为了拿包。睡觉照样 1 点，尿酸也没管。挡住它的是奖励只认"有一条记录"，跟睡够、多走路、少喝奶茶都不挂钩。

**卡片文字**：
- 「按 BioAge 包 phenoage_calc.R 的 orig=TRUE 系数计算这个年龄」：读着像 commit message。标题叫「生物年龄与情绪」，正文却全在讲表型年龄，情绪只一句带过。
- 「个人报告只计算报告基因里的连接频率」：我的记录里哪来的报告基因？
- 「个人报告只标出对上哪一组。」：看了等于没看。
- 「人群里的关联不等于因果，也不是你个人的风险。」：每张紫卡都有，看到第五遍就像 lint warning 一样自动跳过了。
- 写得不错的：「活得久还是弱得久」配上「长寿线虫多出来的日子，主要是衰弱期变长」，光看标题就想点开。睡眠 U 形曲线那张，直接把我的睡眠时长分进三组里，这才是我想要的。

**希望它怎么出现**：跟等 agent 的时间挂钩。手环知道我已经坐了两小时，agent 还要跑三分钟，右侧栏来一行"去接杯水，回来正好跑完"，这种我会接受。会让我立刻关掉的：抢焦点的弹窗、看 diff 时冒出拆包动画、提示音、飞书提醒（飞书是上班用的），还有半夜的说教。

**最想改的 3 件事**：
1. 让卡能用。抽到睡眠卡就开一个两周小实验，结果写回卡上，镭射版「算过」留给这种卡。
2. 按我的数据发卡，脂肪肝、尿酸、睡眠优先。算不了的就直接写"缺 X，算不了"，别列一串"只……不……"。
3. 手环同步的数据自动算作记录，奖励挂在真实行为上。

**打分**：好玩 3（规则很诚实，但没有决策）· 有用 3（跟我有关的卡也就十来张）· 坚持两个月 2（第三周开始就只是在清红点）· 推荐 2（我会推荐 LongPi，但不会提图鉴）
