**统一用语建议**
- 本地健康数据存储（Mirobody）对用户一律称「健康数据服务」；不再出现「你放体检报告的地方 / 原来放报告的地方 / 原来的地方」，也不向用户暴露「Mirobody」。参照写法：mirobody-account.ts:133、upload.ts readBack()。
- 保存类动作：「记下 / 记在」→「已记录 / 保存」；失败类：「读不出来 / 读不到 / 没能读到」→「无法读取 / 未读取到」，「连不上」→「无法连接」，「没有写入」→「未写入」。
- 数据离开设备：统一用「发出」（与页面「发出记录」一致），不混用「送出 / 交给 / 发到」。令牌统一为「令牌」，不用「口令」。
- 产品术语保留：图鉴、抽卡、赛季、冻结、简报、复测窗口、打卡（客户端 pill.ts / followup.ts 已使用）。「看医生」属通俗书面语，未作强制替换；仅在与「去 / 带着 / 约上」组合成口语时改为「就诊 / 就医」。
